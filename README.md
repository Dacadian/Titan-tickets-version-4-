# Titan Tickets 🚀

Premier event ticketing platform with **M-Pesa integration**. Built with Next.js 14, Tailwind CSS, and deployed on Vercel.

## ✨ Features
- ⚡ Dynamic event management
- 💳 M-Pesa STK Push payments
- 👨‍💼 Complete admin dashboard
- 📱 Fully responsive design
- 🎨 Black & Orange theme
- 🚀 Vercel optimized
